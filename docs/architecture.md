# VendorSphere AI Architecture

## Description

VendorSphere AI is an AI-powered Vendor Risk and Compliance Management Platform.

## Main Modules

1. Authentication Module
2. Vendor Management Module
3. Contract Management Module
4. Compliance Management Module
5. Risk Assessment Module
6. AI Risk Summary Module
7. API Key Management Module
8. Notification Module
9. Reporting Module
10. Dashboard Module

## Technology Stack

### Frontend
- Angular
